# Romantic Interactive Invitation

Коротко: мобильный адаптивный одностраничный сайт-приглашение.  
Запуск:
1. npm install
2. npm run dev
3. Откройте указанный адрес (обычно http://localhost:5173)

Описание:
- 3 романтических сцены (217 дней → любовь сильнее → приглашение).
- Интерактивный конверт и записка.
- Плавные анимации и мягкий визуальный стиль.
- Нет фотографий, не требуется БД.

Изменение текста:
- Замените строки в `index.html` / `main.js` при необходимости.

Поддержка:
Если хотите, я могу:
- добавить копию текста на английском;
- заменить шрифты или цветовую палитру;
- собрать build (npm run build) и подготовить ZIP.
